# Java Concurrency Study

This repository is a small Java project used to practice the ideas from Java Concurrency in Practice.

## Project structure

- `src/main/java` contains runnable examples and small experiments.
- `src/test/java` contains tests that validate the most important concurrency patterns.

## How to run

```bash
mvn test
```

## Example goals

- expose race conditions
- compare unsafe and safe counters
- practice synchronization concepts
- validate thread-safe behavior with tests
